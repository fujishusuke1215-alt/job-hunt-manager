# AI利用の記録

## 誠実な前提

このプロジェクトは、ユーザーが目的・制約・必須機能・安全条件を提示し、Codexが要件整理、設計提案、コード作成、テスト、修正、文書化を支援して進めるAI協働開発です。「すべてを人間が手書きした」とは説明しません。

## 役割分担

| 主体 | 決めた・行ったこと |
|---|---|
| ユーザー | 実用品・成果物・学習証跡を同等にする目的、必須機能、無課金、個人情報禁止、Gitと証跡の要件 |
| 過去会話 | 実用品70%/成果物30%、35〜50時間相当、評価項目、調査自動化は初版外という方針 |
| AI | 過去仕様の分類、localStorage構成の提案、画面・型・テストの実装、エラー調査、資料の初稿 |
| ユーザーが今後確認すること | 実際に操作し、各フェーズの理解度チェックへ答え、説明を自分の言葉へ直すこと |

## AIを使う際の確認方法

1. 型定義と要件表の項目が一致するかを見る。
2. 自動テストだけでなく、画面で主要操作を確認する。
3. AIが追加した判断は「AI補完」と明記する。
4. 実際に起きたエラーだけを開発ストーリーへ残す。
5. 面接では、理解していない技術を使用経験として誇張しない。

## 面接での短い説明

「要件と安全条件は自分で提示し、Codexを実装・レビュー・テスト支援に使いました。生成結果をそのまま成果とせず、要件との対応、データの流れ、自動テスト、Git差分を確認できる資料を残し、AI補完の判断も分離しています。」
